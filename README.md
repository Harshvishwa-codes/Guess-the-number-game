# Guess the Number Game

This is a simple number guessing game I built while learning Python.

The computer generates a random number between 1 and 100, and the player has five attempts to guess it.

## Features

- Random number generation
- Five attempts to guess the number
- Hints to help the player
- Option to quit the game

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder.
4. Run the Python file:

```bash
python guess_the_number.py
```
